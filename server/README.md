# Сервер Қорған: тревога родственникам через приложение

```
Браслет ──BLE──► Телефон «Я ношу браслет» ──► Сервер (ноутбук) ──push──► Телефон «Я слежу за близким»
                                                   ◄──────────── «Я еду» ◄──────────┘
```

Сервер связывает телефон с браслетом с телефонами родственников, принимает тревогу
и пересылает её им. Родственник отвечает «Я еду», и это видно на телефоне с браслетом.

## 1. Запуск сервера на ноутбуке

Нужен Python 3.10+. Один раз:

```bash
cd server
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

Каждый раз:

```bash
.venv\Scripts\python korgan_server.py
```

Сервер слушает порт **8000**. Проверка: откройте в браузере `http://localhost:8000/health`,
должно быть `{"ok":true,...}`.

Тесты сервера: `.venv\Scripts\python -m pytest -q`.

## 2. Как телефоны найдут сервер

### Вариант А: дома, в одной Wi-Fi сети (для проверки)

1. Узнайте IP ноутбука: `ipconfig` → «IPv4-адрес», например `192.168.10.18`.
2. Адрес сервера для телефонов: `http://192.168.10.18:8000`.
3. При первом запуске Windows спросит про брандмауэр — разрешите доступ для **частных сетей**.
4. Проверьте с телефона: откройте в браузере `http://192.168.10.18:8000/health`.

Работает, только пока оба телефона в той же Wi-Fi сети, что и ноутбук.

### Вариант Б: из любого места (мобильный интернет)

Ноутбуку нужен публичный адрес. Бесплатно, без настройки роутера:

- **Cloudflare Tunnel**: установите `cloudflared` и запустите
  `cloudflared tunnel --url http://localhost:8000`. Он выдаст адрес вида
  `https://xxxx.trycloudflare.com`. Минус: адрес меняется при каждом перезапуске,
  и его придётся заново вводить на телефонах.
- **ngrok**: после регистрации даёт один постоянный бесплатный адрес:
  `ngrok http --url=ваш-адрес.ngrok-free.app 8000`.

> Пока сервер на ноутбуке: если ноутбук выключен, спит или без интернета, тревога через
> приложение не дойдёт. Поэтому на Android по умолчанию стоит режим
> «Приложение, потом SMS» — если сервер недоступен, SMS уходят сразу.
> Для реального использования сервер лучше перенести в облако (VPS).

## 3. Push-уведомления (Firebase)

Без Firebase всё уже работает, но тревога придёт родственнику, **только пока у него
открыто приложение** (оно опрашивает сервер раз в 10 секунд). Чтобы тревога будила
телефон, даже когда приложение закрыто, нужен Firebase Cloud Messaging (бесплатно).

1. Зайдите на <https://console.firebase.google.com>, создайте проект (Google Analytics не нужен).
2. **Добавить приложение → Android**. Имя пакета: `com.aistudio.falldetector.rkvpxm`.
3. Скачайте `google-services.json` и положите в папку `app/` (рядом с `app/build.gradle.kts`).
   Пересоберите приложение.
4. **Настройки проекта → Сервисные аккаунты → Создать закрытый ключ**. Сохраните файл как
   `server/firebase-service-account.json`.

   ⚠️ Это секретный ключ: никому не отправляйте и не публикуйте. Он уже в `server/.gitignore`.
5. Перезапустите сервер. `/health` должен показать `"push_mode": "fcm"`.
6. На телефоне родственника в «Тревогах» должно быть «Push-уведомления включены».

## 4. Настройка телефонов

**Телефон родственника** (Android):
1. Установите приложение, выберите язык → **«Я слежу за близким»**.
2. Введите своё имя и адрес сервера → «Подключиться».
3. Разрешите уведомления.
4. Вкладка **«Близкие» → «Получить код»**. На экране появится 6 цифр (действуют 10 минут).

**Телефон с браслетом**:
1. **Настройки → «Оповещение через приложение»**.
2. Введите адрес сервера → «Подключиться».
3. Введите 6 цифр с телефона родственника → «Связать».
4. Выберите, как оповещать:

| Режим | Что происходит |
|---|---|
| Приложение, потом SMS *(по умолчанию)* | Тревога в приложение. Если за 2 минуты никто не нажал «Я еду» — SMS и звонок |
| Только приложение | Только приложение. SMS — только если сервер недоступен |
| Только SMS и звонок | Как раньше, без сервера |
| Приложение и SMS сразу | Оба канала каждый раз |

К одному телефону с браслетом можно подключить несколько родственников, и наоборот.

**Проверка:** на главном экране телефона с браслетом нажмите «Тест тревоги».
У родственника появится «проверочная тревога» (SMS при тесте не отправляются).

## 5. Чтобы тревога точно разбудила телефон родственника

- **Android 14+**: Настройки → Приложения → Қорған → «Полноэкранные уведомления» → разрешить.
  Иначе тревога придёт обычным уведомлением, без экрана поверх блокировки.
- Отключите для Қорған **оптимизацию батареи** (Настройки → Батарея), особенно на Xiaomi,
  Huawei, Samsung: иначе система может задерживать push.
- Канал уведомлений «Экстренная тревога» не делайте беззвучным.

## 6. iPhone

Приложения для iOS пока нет. Сервер уже умеет отправлять push на iPhone через тот же
Firebase; для iOS-версии понадобятся Mac с Xcode и Apple Developer ($99/год) —
без платного аккаунта Apple не даёт присылать push.

## API (для разработки)

Авторизация: `Authorization: Bearer <device_id>.<secret>` (выдаётся при регистрации).

| Метод | Путь | Кто | Что делает |
|---|---|---|---|
| GET | `/health` | все | проверка, режим push |
| POST | `/api/register` | все | регистрация телефона: `role`, `name`, `platform`, `push_token` |
| PATCH | `/api/me` | все | смена имени / push-токена |
| POST | `/api/pair/code` | родственник | новый код из 6 цифр (10 минут) |
| POST | `/api/pair/join` | с браслетом | связаться по коду (не больше 10 ошибок в час) |
| GET / DELETE | `/api/links`, `/api/links/{id}` | все | список связей / отключить |
| POST | `/api/alerts` | с браслетом | тревога: `kind` FALL/SOS/TEST, текст, координаты, заряд |
| GET | `/api/alerts`, `/api/alerts/{id}` | все | история / статус тревоги |
| POST | `/api/alerts/{id}/ack` | родственник | «Я еду» |

Данные хранятся в `server/korgan.db` (SQLite).
