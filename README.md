# Қорған

Android-приложение для мониторинга датчика падения ESP32-C3 и отправки экстренного оповещения.

Приложение подключается к датчику по Bluetooth LE, показывает состояние соединения и журнал событий. При тревоге оно может отправить SMS с местоположением и выполнить экстренный вызов с голосовым сообщением. Доступные способы оповещения настраиваются в приложении.

## Чтобы тревога срабатывала при заблокированном экране

Начиная с Android 10 приложение не может само открыть экран из фона, а на Android 14+ для полноэкранной тревоги нужно отдельное разрешение. Приложение проверяет это в разделе **Настройки → Надёжность тревоги** и показывает предупреждение на главном экране.

Обязательно включите:

1. **Уведомления** для приложения.
2. **Полноэкранные уведомления** (Android 14+): Настройки → Приложения → Қорған → Полноэкранные уведомления.
3. **Работа без ограничений батареи**: Настройки → Приложения → Қорған → Батарея → Без ограничений.
4. **Автозапуск** на Xiaomi/Redmi, Huawei/Honor, Samsung, OPPO, vivo и realme, а также снимите ограничения фоновой активности для приложения.

В приложении откройте **Настройки → Надёжность тревоги → Настроить по шагам**: мастер сам покажет следующее недостающее разрешение и откроет нужный системный экран. После возврата в приложение он перейдёт к следующему шагу.

**«Не беспокоить» — необязательно.** Звук тревоги воспроизводится как будильник и обычно слышен даже в этом режиме. Разрешение нужно только для показа уведомления в «Не беспокоить». Если вы им пользуетесь, путь на Samsung: Настройки → Приложения → ⋮ (три точки справа вверху) → Специальный доступ → Доступ к режиму «Не беспокоить» → Қорған → включить.

После настройки нажмите **Настройки → Надёжность тревоги → Проверить тревогу через 10 секунд** и заблокируйте экран. Должны появиться полноэкранная тревога, звук и вибрация.

## Основные возможности

- Подключение к датчику ESP32-C3 по Bluetooth LE.
- Отображение состояния датчика, местоположения и последних событий.
- Экстренное SMS и голосовой вызов с настраиваемым сообщением.
- Тревога родственникам в приложение Қорған через свой сервер, с ответом «Я еду»
  ([как запустить сервер и связать телефоны](server/README.md)).
- Настройка контактного номера, способов оповещения и обратного отсчёта.
- Интерфейс на русском, казахском и английском языках.

## Установка из исходного кода

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта в Android Studio и дождитесь синхронизации Gradle.
3. Подключите Android-устройство или запустите эмулятор.
4. Нажмите **Run** в Android Studio.

Для сборки отладочного APK в PowerShell выполните:

```powershell
.\gradlew.bat assembleDebug
```

APK будет создан здесь: `app/build/outputs/apk/debug/app-debug.apk`.
