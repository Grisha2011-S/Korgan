# Қорған

Android-приложение для мониторинга датчика падения ESP32-C3 и отправки экстренного оповещения.

Приложение подключается к датчику по Bluetooth LE, показывает состояние соединения и журнал событий. При тревоге оно может отправить SMS с местоположением и выполнить экстренный вызов с голосовым сообщением. Доступные способы оповещения настраиваются в приложении.

## Основные возможности

- Подключение к датчику ESP32-C3 по Bluetooth LE.
- Отображение состояния датчика, местоположения и последних событий.
- Экстренное SMS и голосовой вызов с настраиваемым сообщением.
- Настройка контактного номера, способов оповещения и обратного отсчёта.
- Интерфейс на русском, казахском и английском языках.

## Установка из исходного кода

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта в Android Studio и дождитесь синхронизации Gradle.
3. Подключите Android-устройство или запустите эмулятор.
4. Нажмите **Run** в Android Studio.

Для сборки отладочного APK в PowerShell выполните:

```powershell
.\gradlew.bat assembleDebug
```

APK будет создан здесь: `app/build/outputs/apk/debug/app-debug.apk`.
